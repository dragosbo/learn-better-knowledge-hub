Agent Gateway • REST Endpoints

Headless Programmatic Endpoints: Zero-Friction REST

Executable server-side endpoints designed exclusively for machine consumption.

GET /api/agent/capabilities Manifest

Returns complete machine-readable ledger of all 15 capabilities, deliverable files, and reliable contracts.

GET /api/agent/schema Validation

Exposes formal JSON Schemas for Playlist, YouTubeClip, CosmosNode, Cluster, and StudyNotes.

GET /api/agent/tools Functions

Returns universal Function Calling schemas ready for injection into LLM system prompts.

POST /api/agent/execute-tool Execution

Receives structured tool invocation calls, validates parameters, and returns verified deterministic results.

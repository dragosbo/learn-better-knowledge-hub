Security Architecture

The Sandboxed Iframe Security Model

Embedding external or legacy HTML files requires careful attribute configuration to maintain security without breaking client scripting:

React Iframe Invocation (LegacyAppsHub.tsx)
<iframe
  key={iframeKey}
  src={selectedApp.url}
  title={selectedApp.title}
  className="w-full h-full border-0 rounded-xl"
  sandbox="allow-scripts allow-same-origin allow-popups allow-downloads"
  loading="lazy"
/>
allow-scripts: Enables legacy D3 animations, client search, and event handlers.
allow-same-origin: Lets standalone apps load companion JSON files from /data/*.
allow-popups: Permits clicking YouTube external links into new tabs safely.
Omitted allow-top-navigation: Prevents legacy scripts from redirecting the parent applet.
🔒 Protection: Strict sandboxing guarantees that legacy script errors cannot crash the main React UI.
Backend Routing

Dual-Route Serving: server.ts Static Asset Resolution

To support both clean dashboard URLs and direct bookmarks from the original repository, Express serves files via a dual-route hierarchy:

Route A: Dedicated Namespace
app.use('/legacy', express.static(importedDir))

Prevents route collisions with React routes. All standalone apps are cleanly isolated under /legacy/*.html with correct MIME headers.

Route B: Root Bookmark Compatibility
GET /youtube.html → /legacy/youtube.html

Express transparently redirects root requests to the canonical legacy path, ensuring old links never return 404 errors.

Cache Policy: Cache-Control: no-cache for development • X-Frame-Options: SAMEORIGIN 100% Endpoint Health
Asset Safety

Preventing CSS & Global JavaScript Pollution

Legacy HTML apps often declare un-scoped CSS resets (e.g. * { box-sizing: border-box; margin: 0; }) and mutate window.* globals. If rendered directly in React, they destroy dashboard layout styling.

CSS Namespace Isolation

Tailwind CSS v4 in the parent React applet remains completely immune to inline <style> blocks inside the legacy pages.

JavaScript Window Scope

Variables like window.data or window.$ in legacy scripts live inside the iframe's distinct global window context.

Independent Garbage Collection

When the user switches tabs, unmounting the iframe immediately frees DOM nodes and canvas memory without memory leaks.

🧼 Clean Architecture: The host application stays pristine while legacy tools run at native speed.

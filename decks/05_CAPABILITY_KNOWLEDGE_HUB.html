The Illusion of Competence

Passive watching creates a false signal of mastery. When you observe an expert coder, mirror neurons light up, but synaptic consolidation does not occur:

1. The Ebbinghaus Forgetting Curve

Without retrieval practice, 50% of technical information is lost within 1 hour, and 80% decays within 48 hours of watching a video.

2. Note-Taking Typing Latency

Typing is a 40-word-per-minute bottleneck that disrupts the speaker's flow. Speaking is 150 words per minute, capturing raw cognitive momentum.

3. The Generation Effect

Information generated by the learner's own voice is remembered up to 300% better than information merely read or heard passively.

The Socratic Interrogation Loop

Every interview session enforces a rigorous tripartite cognitive structure:

Stage 1: Merits & Value Why was this lecture standout? Grounds motivation and emotional saliency.
Stage 2: Key Learnings What specific technique was new? Forces precise semantic articulation.
Stage 3: Practical Application How will you execute this in code? Connects theory directly to IDE action.

const drawNotebookRules = () => {
  // 1. Subtle warm paper background
  doc.setFillColor(252, 252, 250);
  doc.rect(0, 0, pageWidth, pageHeight, 'F');

  // 2. Horizontal faint ruled lines (7.5mm interval)
  doc.setDrawColor(230, 235, 240);
  doc.setLineWidth(0.12);
  for (let y = 30; y < 275; y += 7.5) {
    doc.line(leftMargin, y, rightMargin, y);
  }

  // 3. Classic red Cornell vertical margin guide
  doc.setDrawColor(239, 68, 68); // Soft red
  doc.setLineWidth(0.3);
  doc.line(marginLineX, 16, marginLineX, 280);

  // 4. Second faint parallel registration track
  doc.setDrawColor(254, 202, 202);
  doc.setLineWidth(0.1);
  doc.line(marginLineX + 0.8, 16, marginLineX + 0.8, 280);
};

Safe GitHub Sync & Multi-AI Monorepo Protocol

When multiple autonomous AI tools (Claude Code, Kiro AI, Gemini AI Studio) work on the same GitHub repository (dragosbo/learn-better), naive git commits result in devastating collisions. Capability 12 introduces a battle-tested protocol: isolated branch staging, non-destructive subfolder quarantine (webapp/), and automated sync scripts.

🛡️ Non-Destructive Quarantine

The AI Studio React SPA installs exclusively into webapp/, ensuring existing code/, lib/, and notebooks/ remain 100% untouched.

🌐 Direct GitHub REST Service

In-app client-side GitHub API integration (githubApi.ts, 944 lines) pulling remote trees, tokens, and rate limits with zero build dependencies.

The Problem Space • Multi-AI Collision Hazard

Why Multi-AI Monorepos Fail Without Branch Quarantine

Three autonomous AI coding agents co-developing in a single Git repository create unique, catastrophic failure modes.

Claude Code CLI Terminal Agent

Modifies root-level Python scripts (code/, lib/), rewrites bash scripts, and produces Jupyter notebooks for data analysis.

Risk: Overwriting root package.json or git tracking index.
Kiro AI Agent Task Automator

Refactors course structures, processes raw video audio into transcripts, and creates automated test runbooks in markdown.

Risk: Uncommitted working tree state colliding during pull.
Gemini AI Studio Cloud Web Engine

Generates complete React 19 SPA, Tailwind UI components, Express server proxy routes, and interactive slide presentations.

Risk: Flattening existing repository files upon merge.
The Golden Rule: Never merge directly into main from an AI Studio session. Always quarantine in a feature branch.
Architecture Solution • Monorepo Topology

The Safe Sync Topology: Quarantine in webapp/

How the unified repository organizes Python scripts, legacy HTML tools, and the React web app without overlap.

// Target Repository Root (dragosbo/learn-better)
├── code/ # 15 Python operational scripts (untouched)
│ ├── read_channel.py

├── notebooks/ # Jupyter research notebooks
├── webapp/ # AI Studio Web Hub Quarantine
│ ├── src/ (React 19 SPA, components, data)
│ ├── public/ (assets, decks, videos)
│ ├── package.json & vite.config.ts
│ └── server.ts (Express proxy & static)

├── gemini_feedback.md # Architecture feedback log

Three Immutable Principles:
  • ✓ 1. Zero Root Contamination: No `node_modules` or `package.json` in the root repository folder.
  • ✓ 2. Preserved Python Paths: Scripts in `code/` continue to execute with original relative paths to `data/`.
  • ✓ 3. Lineage Preservation: Audit markdown documents sit at root for immediate visibility in GitHub web view.
Result: Zero git conflicts when pulling updates between AI Studio and local development.

Automation Engine • Cross-Platform Scripts

Automated Export Scripts: Linux, macOS & Windows

Two turn-key automation scripts handle the entire synchronization sequence in a single terminal command.

export_to_github.sh (Bash) macOS / Linux / WSL
./export_to_github.sh /path/to/learn-better
  • • Validates .git folder existence before touching files
  • • Creates branch feature/gemini-knowledge-hub
  • • Copies src/, public/, and config files into webapp/
  • • Syncs gemini_prompts.md audit logs to root
export_to_github.bat (Windows) Windows CMD / PowerShell
export_to_github.bat C:\repos\learn-better
  • • Native Windows batch syntax with robocopy /E
  • • Preserves Windows CRLF line endings automatically
  • • Includes safety prompt before staging files into git
  • • Generates ready-to-run push instructions in command prompt
Run from your terminal or CI runner: git status → 0 root conflicts guaranteed
Client-Side REST Integration • githubApi.ts

Direct GitHub REST API Service: Ingestion & Traversal

The application doesn't just push code to GitHub—it pulls live repository contents directly into client state via src/services/githubApi.ts.

1. PAT & Rate Limits

Stores Personal Access Tokens in localStorage, tracks API rate limit quotas (60 unauth vs 5,000 auth requests/hr), and displays live reset timers.

2. Recursive Tree Ingestion

Uses the Git Trees API (recursive=1) to fetch the entire repository file hierarchy in a single network round-trip.

3. UTF-8 Base64 Decoder

Custom multi-byte UTF-8 decoder preventing garbled text when decoding markdown notes, mathematical formulas, and Romanian diacritics.

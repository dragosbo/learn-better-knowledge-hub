The Lexical Mismatch Bottleneck

In technical video education, search engines expect exact string matching. But real cognitive mastery relies on conceptual overlap and contextual association:

1. Lexical Blindness

Learners cannot query concepts they haven't encountered yet. Searching for "neural logic" yields zero results when the lecture is titled "Causal Self-Attention".

2. Lack of Frequency Signal

A video playlist with 30 titles does not indicate whether "Backpropagation" is mentioned once in passing or serves as the mathematical foundation for 15 hours of coursework.

3. Disconnected Linearity

Linear playlist order forces artificial chronology. A word cloud liberates terms from chronological isolation into a flat, instantly grokkable semantic field.

The Solution: Two-Stage Cognitive Extraction Stage 1 + Stage 2
Stage 1: Frequency Concept Cloud

Answers: "What technical vocabulary dominates this learning track?" Displays terms sized by proportional corpus occurrence, color-coded by cognitive domain.

Stage 2: 3-Tier Radial Mind Map

Answers: "How do these terms connect to foundational thesis pillars and concrete video lectures?" Anchors abstract vocabulary into concrete learning steps.

Client-Side NLP Pipeline

The tokenization engine processes playlist metadata and user notes in 0 network roundtrips:

1 Corpus Aggregation (Titles, tags, notes, Q&A)
2 Lowercasing & regex alphanumeric tokenization
3 Stopword elimination (English + YouTube noise)
4 Frequency counting, sorting, & weight truncation
src/data/wordcloudMindmapData.ts TypeScript 
export function computePlaylistWordCloud(playlist: Playlist): PlaylistWordCloudData {
  // 1. Aggregate text corpus across all clips
  const textCorpus = [
    playlist.title,
    playlist.description || '',
    ...playlist.clips.map(c => `\${c.title} \${c.tags.join(' ')} \${c.notes || ''}`)
  ].join(' ').toLowerCase();

  // 2. Tokenize alphanumeric words
  const rawTokens = textCorpus.match(/[a-z0-9_-]+/g) || [];

  // 3. Filter stopwords (prepositions + video noise)
  const frequencyMap = new Map<string, number>();
  for (const token of rawTokens) {
    if (token.length >= 3 && !STOP_WORDS.has(token)) {
      frequencyMap.set(token, (frequencyMap.get(token) || 0) + 1);
    }
  }

  // 4. Sort descending and assign contextual categories
  const words = Array.from(frequencyMap.entries())
    .filter(([_, weight]) => weight >= 2)
    .sort((a, b) => b[1] - a[1])
    .slice(0, 50);
  return { playlistId: playlist.id, words, ... };
}

The MindMapNode Contract

A strictly-typed recursive tree structure bridging abstract curriculum goals to concrete video clips:

Tier 1: Master Root Node Thematic thesis covering the entire playlist curriculum.
Tier 2: Conceptual Pillars 5 structural branches dividing the domain into distinct competencies.
Tier 3: Concrete Video Leaves Direct YouTube video IDs, duration, channel, and synthesized takeaways.
src/types/index.ts TypeScript Interface 
export interface MindMapNode {
  id: string;             // e.g. 'root-intelligence', 'branch-origins'
  label: string;          // Display title
  level: 1 | 2 | 3;       // Tier depth
  description?: string;   // Pedagogical summary
  color?: string;         // Branch theme color

  // Tier 3 Video Leaf Attributes
  clipId?: string;        // YouTube Video ID (e.g. 'G5sxVf9K-_c')
  clipTitle?: string;     // Video title
  channel?: string;       // Creator / Channel
  duration?: string;      // Playtime (e.g. '18:24')
  keyTakeaway?: string;   // Synthesized learning insight
  keywords?: string[];    // Associated vocabulary tokens

  children?: MindMapNode[]; // Recursive children for Tiers 1 & 2
}

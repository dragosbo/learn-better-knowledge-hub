Operating System Friction

The Mobile Safari Barrier: Background Audio Killing

Why running audio in mobile web browsers fails without specialized architectural countermeasures.

Mobile Safari Failure Modes
  • Timer Freezing: Lock screen or tab switch immediately freezes setTimeout and setInterval loops.
  • Speech Synthesis Suspension: WebKit throttles speech audio after 15 seconds of inactivity.
  • Hardware Signal Hijacking: Without MediaSession registration, earbud pinches launch Apple Music or Spotify instead.
Learn Better Countermeasures
  • MediaSession Registration: Informs iOS/Android that this tab is an active media player.
  • Atomic Paragraph Chunking: Avoids monolithic text blobs; synthetically speaks paragraph-by-paragraph.
  • AVRCP Action Trapping: Directly traps play, pause, seekforward, and seekbackward events.
Rule: Never pass >300 words into a single SpeechSynthesisUtterance on Mobile WebKit.
Speech Synthesis Mechanics

Utterance Dispatcher & Paragraph Chunking

How the engine manages asynchronous boundary callbacks and rate transitions without audio distortion.

// Chunked Speech Dispatcher with Dynamic Rate Override
const speakParagraph = (index: number, overrideRate?: number) => {
window.speechSynthesis.cancel();
const utterance = new SpeechSynthesisUtterance(spokenParagraphs[index]);
utterance.rate = overrideRate !== undefined ? overrideRate : rateRef.current;
utterance.onend = () => {
const nextIdx = paragraphIndexRef.current + 1;
if (nextIdx < spokenParagraphs.length) {
speakParagraph(nextIdx, rateRef.current);
} else { handleStop(); }
};
window.speechSynthesis.speak(utterance);
};

Hardware Gesture Mapping

The AirPods Stem Pinch Gesture Matrix

Physical earbud force sensor events mapped directly to state machine action handlers.

AirPods Stem Pinch W3C Action Handler Audio Player Handler Behavior in App
Single Pinch setActionHandler('play' / 'pause') handleResume() / handlePause() Pauses or resumes speech at exact current word index.
Double Pinch setActionHandler('seekforward') handleNext() Skips forward to next concept paragraph.
Triple Pinch setActionHandler('seekbackward') handlePrevious() Rewinds to start of previous paragraph to re-listen.

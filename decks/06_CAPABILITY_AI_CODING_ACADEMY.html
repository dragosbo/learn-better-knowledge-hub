Architect Mindset

Begins with project boundaries, directory structures, and contract definitions before writing a single line of application code.

Hacker Mindset

Prioritizes early tangible wins in 45 minutes, then refactors messy working scripts into clean reusable libraries.

  • 1. Early Win Script: Zero-API-key audio and transcript download working in lesson 2.
  • 2. Local AI Inference: Integrates `faster-whisper` and `Piper TTS` directly on local hardware.
  • 3. Refactoring to lib/: Extracts repeated HTTP, YouTube, and text utilities into shared modules.

Masterclass The 4 Immutable Laws of Professional Vibe Coding
Slide 5 of 8
Law 1: The Contract-First Principle Inputs ➔ Outputs

Never say "build me an app." Always specify input schemas, output formats (JSON/Markdown), and mandate dedicated experiment directories (e.g. /webapp/).

Law 2: Context Window Conservation Daily Free Quotas

Never paste entire codebases into context. Reference specific file paths and line ranges. Structure work into single-outcome micro-sprints.

Law 3: Multi-AI Specialization Matrix Model Affinity

Assign work by cognitive sweet spot: Kiro for terminal and local scripts; Claude for deep architectural specs; Gemini for fast full-stack synthesis.

Law 4: The Deterministic Verification Gate Exit Code 0

Every step must conclude with an executable verification command (e.g. npm run build && npm run lint). Never accept code without proof of compilation.

The Problem Slide 2 of 7

Why YouTube Fails Serious Learners

YouTube is optimized for endless algorithmic discovery, not systematic pedagogical retention.

1. Continuation Token Trap

YouTube web interfaces only show the first ~30 playlists. The rest are buried behind hidden continuation tokens.

2. Zero Cross-Playlist Search

Searching within your own channel or finding a specific lecture across 50 playlists is virtually impossible.

3. No Learning State

No way to track which clips have personal study notes, extracted questions, or synthesis status.

✓

The Solution: Learn Better normalizes the entire channel into an indexed catalog with sub-millisecond local filtering.

Architecture Slide 3 of 7

Contract-First Data Design

Clean TypeScript types bridge YouTube API scraping, local JSON persistence, and React state.

Universal Data Contracts
interface YouTubeClip {
  id: string;               // YouTube video ID
  title: string;
  duration?: string;
  notes?: string;           // User markdown study notes
  userQuestions?: string[]; // Open research questions
  userIdeas?: string[];     // Vibe coding ideas
  status?: 'to-watch' | 'watching' | 
           'reviewed' | 'synthesized';
}

interface Playlist {
  id: string;
  title: string;
  category: string;         // 1 of 5 domains
  clips: YouTubeClip[];
}
Data Lifecycle Pipeline
1. Ingestion: Python & Innertube scripts fetch channel and write `channelPlaylists.json`.
2. API: Express endpoint `/api/content/playlists` serves catalog on boot.
3. Cache: Browser caches in `localStorage` for instant offline boot.
4. Persistence: Updates auto-save to disk via `/api/content/save-playlists`.
Zero external cloud databases required • Completely portable across machines and platforms

Automation Slide 6 of 7

Live YouTube Sync Pipeline

How `/api/content/sync-youtube` refreshes videos without destroying your local study notes.

The Non-Destructive Ingestion Algorithm:
1. Traverse Innertube continuation tokens for channel @dragosborosgpt
2. Load current channelPlaylists.json into memory
3. For every incoming video ID:
✓ If already exists: PRESERVE existing notes, status, & questions
✓ If new: Append to matching playlist with default to-watch status
4. Atomically persist updated database to disk and reload React client
🛡️

Zero Mutation Guarantee: You can click "Sync with YouTube" at any time. Your handwritten notes, AI prompts, and voice transcripts will never be overwritten.

Channel: @dragosborosgpt Route: POST /api/content/sync-youtube

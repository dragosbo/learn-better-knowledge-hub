🔌 Programmatic Agent Endpoints

Real-Time Server Endpoints
GET /api/agent/capabilities

Returns all 14 platform capabilities in strict machine-readable JSON format, including file dependencies, line ranges, primary UI components, backend endpoints, and data contracts.

GET /api/agent/schema

Exports complete JSON Schema definitions for core domain models (YouTubeClip, Playlist, CosmosVideoNode, RestructureCluster, StudyNote).

GET /api/agent/tools

Returns ready-to-use Function Calling tool declarations in standard OpenAI / Gemini format for autonomous tool calling.

POST /api/agent/execute-tool

Executes an agent tool call securely server-side against live repository datasets and returns typed responses.
